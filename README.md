# Springfield CAD

Windows x64 desktop app for [Springfield CAD](https://cad.springfieldrp.qd.je/).

[Download Springfield CAD 1.0.2](https://github.com/moessacr7-ship-it/springfield-downloads/releases/download/v1.0.2/Springfield-CAD-Setup.exe)

[Release notes and checksum](https://github.com/moessacr7-ship-it/springfield-downloads/releases/tag/v1.0.2)

The installer is unsigned. An internet connection and your Springfield Discord account are required. Website access follows your current permissions.
